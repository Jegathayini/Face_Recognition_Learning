# Computer Vision and Face Recognition Learning Journey

## Overview

This repository documents my learning journey in Computer Vision, OpenCV, Image Processing, and Face Recognition using Python.

The repository contains notes, practice exercises, experiments, and mini-projects completed while exploring the fundamentals of computer vision and artificial intelligence.

---

## Objectives

- Learn Python for Computer Vision
- Understand digital image representation
- Explore OpenCV fundamentals
- Work with webcam and video streams
- Perform image processing operations
- Learn face detection techniques
- Learn face recognition concepts
- Build practical Computer Vision applications
